# แพลนของฉัน — Android

แอปวางแผนงานรายสัปดาห์แบบติดตั้งบน Android

## วิธีสร้าง APK ด้วย Android Studio
1. เปิดโฟลเดอร์นี้ด้วย Android Studio
2. รอ Gradle Sync
3. เลือก Build > Build App Bundle(s) / APK(s) > Build APK(s)
4. ไฟล์ APK จะอยู่ใน `app/build/outputs/apk/debug/`

## ฟังก์ชันในรุ่นนี้
- หน้าหลักและภาพรวมงาน
- ตารางงานรายสัปดาห์
- เพิ่มงานพร้อมเวลาและประเภท
- แตะงานเพื่อทำเครื่องหมายเสร็จ
- รายงานสรุป
- บันทึกงานในเครื่องด้วย localStorage
